How to type names
  • One name per line. Paste from Excel, Sheets or WhatsApp works too.
  • Level after a comma: A strong, I middle, B beginner. Strong players are kept apart and get byes first.
  • A line like # U12 starts a separate draw for that category.
  • The list is remembered on this device.
More options

The same names and the same draw number always give the same draw.
